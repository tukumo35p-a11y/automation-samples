# Sales data cleanup and Excel report

Takes a messy sales export and produces a clean data file plus a formatted Excel report, in one command.

## The problem it solves

Exports from sales tools and shared spreadsheets are rarely ready to use. The sample file here, [sample_data/raw_sales.csv](sample_data/raw_sales.csv), has the usual problems:

- Dates in four formats (`2026-03-05`, `03/05/2026`, `5 Mar 2026`, `March 5, 2026`)
- Prices written as `$1,249.00`, `1249.00`, or with stray spaces
- Quantities such as `3 pcs`, blank, or negative
- Names in mixed case with extra spaces (`  ACME CORP `)
- Rows exported twice

The data is synthetic and generated by `make_sample_data.py`.

## What you get

- [sample_output/cleaned_sales.csv](sample_output/cleaned_sales.csv): one consistent row per order
- [sample_output/sales_report.xlsx](sample_output/sales_report.xlsx): five sheets

| Sheet | Contents |
|---|---|
| Summary | Row counts, date range, total units, total revenue, average order value |
| By Month | Orders, units, and revenue per month, with a bar chart |
| By Product | Same, per product, highest revenue first |
| By Region | Same, per region |
| Issues | Every removed row, with its order ID and the reason |

For the sample file: 312 rows in, 274 clean orders out, 38 rows removed and listed in the Issues sheet.

## Run it

```
python clean_and_report.py sample_data/raw_sales.csv
python clean_and_report.py your_export.csv --out-dir results
```

To regenerate the sample data: `python make_sample_data.py`

## How it behaves

- Nothing is dropped silently. Every removed row is recorded with the reason, so the numbers can be checked against the source.
- Stops with a clear message if a required column is missing.
- The monthly, product, and region totals all add up to the same total revenue.

## Adapting it

Column names, cleaning rules, and report sheets are each defined in their own function. Typical changes are adding a column, changing what counts as an invalid row, or adding a breakdown such as revenue per customer.
